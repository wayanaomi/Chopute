This directory holds the official Chopute brand assets supplied by the
client. They are referenced directly by `src/components/brand/chopute-logo.tsx`
and must be placed here with these exact filenames:

- `chopute-logo.png` — full lockup (wordmark + "AUTOMATIC LEADS. REAL GROWTH."
  tagline). Used in the landing page header/footer and the auth screen.
- `chopute-icon.png` — icon-only mark (the "C" + magnifying glass/person
  glyph). Used for the compact authenticated-app header and as the source
  for `app/icon.png` / favicon generation.

Do not regenerate these assets with text or a substitute logo — copy the
exact files the client provided into this folder using these filenames.
